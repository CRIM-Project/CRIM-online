# CRIM-online
Django project for [CRIM (Citations: The Renaissance Imitation Mass)](https://crimproject.org/)

Learn more about CRIM here: https://sites.google.com/haverford.edu/crim-project/home

Read the [Thesaurus of Musical Types](https://github.com/CRIM-Project/CRIM-online/blob/master/CRIM_Musical_Types_Thesaurus.md) and [Thesaurus of Relationship Types](https://github.com/CRIM-Project/CRIM-online/blob/master/CRIM_Relationship_Type_Thesaurus.md)

Also learn about [CRIM Intervals](https://github.com/HCDigitalScholarship/intervals), a Python library for analysis of Renaissance counterpoint.
